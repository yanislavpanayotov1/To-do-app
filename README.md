# To-Do App

A simple and interactive **To-Do list** application that allows users to manage their tasks efficiently. Users can add, edit, delete, and mark tasks as completed, helping them stay organized.

## Demo

Check out the live version of the app: [To-Do App Demo]([link_to_your_live_version](https://to-do-app-yani.netlify.app))

## Features

- **Add tasks**: Users can add new tasks with descriptions.
- **Edit tasks**: Modify existing tasks.
- **Delete tasks**: Remove completed or unnecessary tasks.
- **Mark as completed**: Track the status of each task (completed or pending).
- **Responsive Design**: The app works seamlessly on all devices (mobile, tablet, desktop).

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript (ES6+), React
- **State Management**: React Hooks 
- **Deployment**: Netlify for hosting

## Installation

### Clone the repository:

```bash
git clone https://github.com/yanislavpanayotov1/To-do-app.git
cd To-do-app
```
Install dependencies:
```bash
npm install
```

Run the app locally:
```bash
npm start
```
Navigate to `http://localhost:3000` in your browser to view the app.
